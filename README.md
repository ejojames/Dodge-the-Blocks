# Dodge the Blocks 🚀

A fun and challenging **dodge-the-blocks game** built with **Pygame** and **pygame_gui**.  
Dodge falling blocks, keep your lives, and try to get the highest score!  

---

## Features

- 5 lives per game
- Selectable difficulty: Easy, Medium, Hard
- Pause and resume during gameplay
- Midway quit with confirmation popup
- Score and lives displayed on screen
- Human-friendly, readable code

---

## How to Play

1. Move left/right with **arrow keys**.
2. Avoid falling blocks.
3. Press **Q** to quit to main menu anytime.
4. Press **ESC** to pause.
5. Survive as long as possible and get a high score!
